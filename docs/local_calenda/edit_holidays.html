🏛️ 명절 및 공휴일 편집기

※ 명절, 국정 후무일 등의 고정적인 양력 사용 행사일정을 기준하세요. 도움말 참조.

ID 날짜 (YYYY-MM-DD) 종류 명절/공휴일 내용 (제목) 삭제

※ 변경 후 📥 저장하기를 반드시 수행하세요.

💡 편집기 이용 가이드

  • 일자 정렬: 연도를 무시하고 1월부터 12월까지 순서대로 정렬하며,
          📥 저장하기 클릭시 즉시 저장소에 📥 다운로드 됩니다.

  • 날짜 색상 안내:
    • 청색: 올해 기준으로 이미 지난 날짜
    • 검정색: 다가오거나 오늘인 날짜

  • 📥 저장하기: 변경된 내용을 저장함과 동시에 holidays.js 파일이 다운로드됩니다. 다운로드된 파일을 프로젝트 폴더에 덮어씌워 주세요.


  • 입력 활용하기: holidays.js 파일을 기준합니다.
      행주가 클릭   일자만 맞게 선택 - 종류 입력 - 행사명 입력
      📥 저장하기 클릭하여 다운로드
      다운로드된 폴더에서 holidays.js 파일을 해당 폴더로 이동복사
      새로고침 (F5) 를 하면 변경된 내용이 달력에 적용됨니다.
