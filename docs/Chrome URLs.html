디버그용 명령 URL (Command URLs for Debug)

이 URL들은 디버깅 목적으로만 사용됩니다.
브라우저를 강제로 종료하거나 멈추게 하므로 링크로 제공되지 않으며,
필요 시 주소창에 직접 입력해야 합니다.

  • chrome://crash
  • chrome://kill
  • chrome://hang
  • chrome://restart
