크롬 내부 URL 전체 완전 분석서

제공된 HTML 소스 코드에 등장하는 모든 일반 주소, 내부 분석 주소(Internals), 비공개 디버깅 주소, 강제 에러 명령어를 하나도 빠짐없이 번역 및 정리한 문서입니다.

1. 일반 및 내부 기능 URL 목록 (List of Chrome URLs)

크롬 브라우저가 자체적으로 제공하는 관리 화면 및 모니터링 페이지 인터페이스입니다. (일부 링크가 동작하지 않는 주소는 크롬 보안 정책상 주소창에 직접 쳐야 이동합니다.)

URL 주소 기능 명칭 및 한글 번역 설명
chrome://access-code-cast 액세스 코드 기반 전송: 학교나 기업 환경에서 고유 코드를 입력해 화면을 캐스팅(전송)하는 기능입니다.
chrome://settings 크롬 메인 설정: 사용자가 마주하는 브라우저의 핵심 환경 설정 기지입니다. (`chrome://settings/privacy` 등으로 세부 라우팅 가능)
chrome://restart 크롬 재시작: 현재 열린 모든 탭과 창을 기억해 둔 채 브라우저를 즉시 완전히 껐다가 1초 만에 그대로 복구하며 자동 재실행합니다.
chrome://accessibility 접근성 검사기: 시각장애인용 스크린 리더 등이 웹페이지 구조를 읽을 수 있도록 브라우저가 생성한 접근성 트리를 분석하고 수정합니다.
chrome://accessibility-annotator-info 접근성 주석 정보: 화면의 이미지나 요소를 AI가 자동으로 분석하여 접근성 텍스트 주석을 달아주는 기능의 상태 정보입니다.
chrome://actor-overlay 액터 오버레이: 크롬 시스템 UI 렌더링 시 특정 오버레이 화면이나 팝업 레이어를 제어하는 내부 도구입니다.
chrome://app-service-internals 앱 서비스 내부 정보: 크롬 내부에서 실행되는 웹앱(PWA) 및 시스템 앱 서비스들의 아키텍처와 디버깅 정보를 보여줍니다.
chrome://app-settings 앱 개별 설정: 설치된 웹앱(PWA)들의 권한(카메라, 위치 등) 및 알림 설정을 개별적으로 조정하는 페이지입니다.
chrome://apps 크롬 앱스: 크롬 웹스토어 등을 통해 브라우저에 설치한 애플리케이션 및 바로가기 모음 화면입니다.
chrome://attribution-internals 기여도 분석 내부 정보: 개인정보를 보호하며 광고의 클릭 및 전환 효과를 측정하는 기여도 API(Attribution Reporting API) 디버깅 도구입니다.
chrome://autofill-internals 자동 완성 내부 정보: 이름, 주소, 카드번호 등 크롬의 자동 완성 기능이 웹페이지 폼을 분석하고 기록한 로그를 확인합니다.
chrome://batch-upload 일괄 업로드: 로컬에 저장된 북마크, 비밀번호 등의 데이터를 구글 계정 클라우드로 일괄 동기화/업로드하는 임시 세션 페이지입니다.
chrome://blob-internals Blob 데이터 내부 정보: 대용량 이진 데이터(파일, 이미지 등)를 다루는 Blob 객체가 메모리 상에 어떻게 배치되어 있는지 모니터링합니다.
chrome://bluetooth-internals 블루투스 내부 정보: 웹 브라우저가 주변 블루투스(BLE) 기기와 통신할 때 사용하는 어댑터 상태 및 연결 신호를 스캔하고 테스트합니다.
chrome://bookmarks 북마크 관리자: 사용자가 저장한 즐겨찾기 목록을 수정, 삭제, 폴더별 백업 및 분류하는 메인 페이지입니다.
chrome://bookmarks-side-panel.top-chrome 북마크 사이드 패널 UI: 크롬 우측 사이드바에 나타나는 전용 북마크 탐색 창의 독립 UI 컴포넌트입니다.
chrome://browser-switch 브라우저 자동 전환: 기업 환경에서 특정 구형 웹사이트 접속 시 인터넷 익스플로러(IE)나 에지 등 다른 브라우저로 자동 연동해주는 기능의 설정입니다.
chrome://cast-feedback 화면 전송 피드백: 크롬캐스트를 이용한 미디어 화면 전송 중 에러가 났을 때 구글에 오류 보고서를 제출하는 팝업 창입니다.
chrome://certificate-manager 인증서 관리자: HTTPS 보안 접속을 위해 컴퓨터 및 브라우저에 등록된 디지털 SSL/TLS 인증서 목록을 관리합니다.
chrome://chrome-signin 크롬 로그인: 브라우저 프로필에 구글 계정을 연동하고 동기화를 활성화하기 위한 로그인 전용 레이아웃입니다.
chrome://chrome-urls 크롬 URL 안내소: 현재 보고 계시는 소스의 본래 페이지로, 크롬이 내장한 모든 특수 주소의 인덱스를 보여줍니다.
chrome://comments-side-panel.top-chrome 댓글 사이드 패널 UI: 웹 문서 공유나 특정 협업 도구 사용 시 사이드바에 활성화되는 댓글 창의 내부 주소입니다.
chrome://components 크롬 구성 요소: 브라우저 핵심 엔진 외에 광고 차단 필터, 보안 모듈 등 개별 부품들의 버전을 확인하고 강제 업데이트합니다.
chrome://conflicts 소프트웨어 충돌 진단: 외부 프로그램(백신, 악성코드 등)이 크롬의 프로세스 메모리에 침범하여 브라우저를 다운시키는지 충돌 모듈을 검사합니다.
chrome://connection-help 연결 도움말: 공공 와이파이 로그인 페이지 리다이렉트 실패 등 네트워크 차단 문제가 발생했을 때 표시되는 안내 도우미입니다.
chrome://connection-monitoring-detected 네트워크 감시 감지 고지: 누군가 중간에서 HTTPS 암호화 패킷을 가로채고 있는 증후(만료된 인증서 강제 주입 등)가 있을 때 경고를 띄웁니다.
chrome://connectors-internals 기업용 커넥터 내부 정보: 기업 보안 관리 시스템(Chrome Enterprise)과 연동되어 파일 유출 방지 및 위협 탐지를 수행하는 커넥터 모듈 상태 창입니다.
chrome://constrained-test 제한적 환경 테스트: 웹 UI 팝업 창이나 다이얼로그가 화면 크기 제약을 받을 때 어떻게 렌더링되는지 개발자가 테스트하는 공간입니다.
chrome://contextual-tasks 맥락 인식 작업: 사용자가 서핑 중인 웹페이지의 문맥을 읽어 AI나 브라우저가 추천 행동을 제안하는 시스템 모듈입니다.
chrome://crashes 오류 보고서 목록: 크롬이 비정상적으로 종료되었을 때 기록된 크래시 로그의 내역 및 구글 서버 전송 상태를 보여줍니다.
chrome://credits 오픈소스 고지: 구글 크롬 브라우저를 구성하기 위해 사용된 수많은 오픈소스 라이브러리와 저작권 라이선스를 투명하게 명시한 곳입니다.
chrome://customize-chrome-side-panel.top-chrome 크롬 맞춤설정 패널: 새 탭의 배경 화면, 테마 색상, 바로가기 아이콘 배치 등을 마우스 클릭으로 편집하는 사이드 패널 화면입니다.
chrome://debug-webuis-disabled WebUI 디버깅 비활성화 안내: 크롬 내부 웹 관리 도구(WebUI)들의 디버그 모드가 꺼져 있을 때 연결되는 상태 안내 페이지입니다.
chrome://default-browser-modal 기본 브라우저 설정 안내창: 크롬을 컴퓨터의 기본 브라우저로 지정하도록 유도하는 팝업 레이아웃입니다.
chrome://device-log 시스템 기기 로그: USB, 블루투스, 프린터, 네트워크 어댑터 등 PC 물리 기기와 크롬 간의 인터랙션 시스템 이벤트를 종합 수집합니다.
chrome://dino 공룡 게임: 인터넷 연결이 끊겼을 때 나타나는 달리는 픽셀 티라노사우루스(T-Rex) 미니 게임을 강제로 실행시켜 줍니다.
chrome://downloads 다운로드 내역: 브라우저를 통해 내 컴퓨터로 내려받은 모든 파일들의 이력과 다운로드 주소 링크를 확인 및 검색합니다.
chrome://drive-picker-host 구글 드라이브 파일 선택기 호스트: 웹페이지에서 구글 클라우드 드라이브에 있는 파일을 바로 첨부하고 불러올 수 있게 연동하는 호스트 인터페이스입니다.
chrome://extensions 확장 프로그램 관리: 사용자가 설치한 서드파티 확장 기능들을 한눈에 보며 개발자 모드 전환, 삭제, 디테일 권한을 수정합니다.
chrome://extensions-internals 확장 프로그램 백엔드 정보: 확장 프로그램들이 내부적으로 사용하는 백그라운드 스크립트, 이벤트 리스너, 스토리지 점유율의 상세 통계입니다.
chrome://extensions-zero-state 확장 프로그램 빈 화면: 설치된 확장 프로그램이 단 하나도 없을 때 웹스토어 방문을 유도하는 인트로 초기 레이아웃입니다.
chrome://feature-showcase 기능 쇼케이스: 크롬 업데이트 후 새롭게 추가된 핵심 편의 기능이나 디자인 변경점을 유저에게 시각적으로 튜토리얼해주는 페이지입니다.
chrome://feedback 의견 보내기: 크롬 사용 중 겪은 버그, 불편 사항, 개선 제안을 스크린샷과 함께 구글 개발팀에 전송하는 양식 창입니다.
chrome://flags 크롬 실험실: 아직 정식 배포되지 않은 최첨단 기능이나 하드웨어 가속, 렌더링 최적화 옵션을 수동으로 활성화/비활성화합니다.
chrome://gcm-internals GCM 내부 정보: 구글 클라우드 메시징(Google Cloud Messaging) 및 웹 푸시 알림 서버와의 통신 지연 시간, 연결 수립 로그를 점검합니다.
chrome://glic 글릭 AI 인터페이스: 크롬 화면 및 문맥을 통째로 이해하고 보조해주는 최신 크롬 내장 AI 비서 기능의 작동 제어판입니다.
chrome://gpu 그래픽 하드웨어 진단: WebGL 및 2D 캔버스 하드웨어 가속 작동 여부, 그래픽 카드 드라이버 버그 우회 리스트 등 화면 렌더링 스펙을 총망라합니다.
chrome://histograms 통계 히스토그램: 크롬이 켜져 있는 동안 내부 프로세스들이 측정한 성능 수치(페이지 로딩 타임, 메모리 할당 속도 등)를 통계 그래프 데이터로 수집한 결과입니다.
chrome://history 방문 기록: 사용자가 접속했던 사이트의 이력을 날짜별, 기기별로 추적하고 개별 웹 쿠키 및 캐시 흔적을 청소할 수 있는 창입니다.
chrome://history-clusters-side-panel.top-chrome 기록 클러스터 패널: 단순 방문 나열이 아닌, 특정 '주제(여행, 쇼핑 등)'별로 묶어서 방문 이력을 탐색해주는 사이드바 전용 뷰어입니다.
chrome://history-side-panel.top-chrome 방문 기록 사이드 패널: 메인 화면을 가리지 않고 화면 우측 좁은 공간에서 빠르게 이전 방문 사이트를 찾을 수 있게 만든 컴포넌트입니다.
chrome://history-sync-optin 기록 동기화 동의창: 스마트폰, 태블릿 등 다른 기기에서 보던 탭을 PC에서도 이어 볼 수 있도록 방문 기록 동기화를 켤지 묻는 화면입니다.
chrome://indexeddb-internals IndexedDB 내부 상태: 웹 애플리케이션들이 사용자 컴퓨터 하드디스크에 대용량 정형 데이터를 저장할 때 쓰는 브라우저 DB의 점유율 및 상태 분석입니다.
chrome://inspect 요소 검사 / 원격 디버깅: 현재 띄워진 웹페이지뿐만 아니라 동일 네트워크에 연결된 안드로이드 스마트폰 크롬의 소스 코드까지 원격 디버깅할 수 있는 개발자 허브입니다.
chrome://internals 종합 내부 정보: 크롬 엔진 내부의 자잘한 하위 시스템 상태를 한눈에 볼 수 있는 인덱스용 라우팅 주소입니다.
chrome://intro 크롬 인트로 안내: 브라우저 최초 설치 또는 메이저 업데이트 이후 크롬의 기본 레이아웃과 생태계를 브리핑해주는 환영 페이지입니다.
chrome://managed-user-profile-notice 관리 대상 프로필 고지: 구글 워크스페이스 학교 계정이나 사내 계정으로 로그인 시, 상위 관리자가 이 프로필의 데이터를 모니터링할 수 있음을 알리는 알림 창입니다.
chrome://management 중앙 관리 상태: 현재 크롬 브라우저가 특정 기업, 학교, 부모(패밀리 링크)에 의해 원격 통제 및 관리되고 있는지 보안 항목을 감사합니다.
chrome://media-engagement 미디어 몰입도 통계: 사용자가 특정 사이트에서 동영상을 얼마나 자주 시청하고 소리를 켰는지 수치화하여, 비디오 자동 재생 여부를 결정하는 크롬 내부 점수판입니다.
chrome://media-internals 미디어 내부 정보: 현재 재생 중인 동영상/오디오의 코덱 스펙, 오디오 샘플링 레이트, 스트리밍 버퍼링 상태 및 하드웨어 디코딩 에러 로그를 기록합니다.
chrome://metrics-internals 사용자 통계 분석 내부 정보: 크롬 브라우저 향상을 위해 구글 서버로 익명 전송되는 브라우저 로딩 속도, 에러율 등 유저 매트릭스 데이터를 모니터링합니다.

chrome://webxr-internals WebXR(가상현실/증강현실) 내부 정보: 웹 브라우저를 VR 헤드셋이나 AR 글래스와 연동하여 가상현실 콘텐츠를 구동할 때의 기기 인식을 진단합니다.

3. 디버그용 강제 오류 명령 URL (Command URLs for Debug)

※ 절대 경고: 아래 주소들은 개발 중 시스템 예외 처리를 유도하기 위한 특수 '명령어 키워드'입니다. 주소창에 직접 타이핑 후 엔터를 치는 즉시 해당 탭 혹은 브라우저 전체가 다운되거나 컴퓨터 메모리가 과부하되므로 중요한 작업 중에는 입력하지 마십시오.

명령어 주소 유발되는 비정상 시스템 강제 현상 설명
chrome://badcastcrash 화면 캐스팅(크롬캐스트) 모듈에 강제로 비정상 패킷을 주입하여 관련 컴포넌트를 다운시킵니다.
chrome://inducebrowsercrashforrealz 진짜 브라우저 전체 종료: 단순 한 개 탭이 아니라, 실행 중인 크롬 브라우저 프로그램 프로세스 자체를 리얼 타임으로 강제 폭파(Crash)시킵니다.
chrome://inducebrowserdcheckforrealz 크롬 소스 코드 내부의 내부 안전 검증 코드(DCHECK 검사문)를 강제로 실패 처리하여 디버깅 어설션 에러를 터트립니다.
chrome://crash 탭 강제 사망: 현재 보고 있는 단일 탭의 렌더러 프로세스를 즉시 종료하여 파란색 배경의 "앗, 이런!" 크래시 화면을 유발합니다.
chrome://crash/rust 최신 크롬에 도입된 Rust 언어로 작성된 내부 모듈 파트에서 메모리 안전성 크래시가 났을 때의 대응 로직을 시뮬레이션합니다.
chrome://crashdump 브라우저를 강제로 크래시시키면서 현재 메모리 상태를 담은 정밀 덤프 파일(.dmp)을 생성하도록 명령합니다.
chrome://kill 현재 활성화된 웹 탭의 프로세스를 OS 작업 관리자에서 '프로세스 끝내기' 한 것과 똑같이 물리적으로 강제 살해합니다.
chrome://hang 현재 탭을 무한 루프 상태에 빠뜨려 마우스 클릭이나 스크롤이 전혀 먹히지 않는 '응답 없음(프리징)' 상태로 만듭니다.
chrome://shorthang 잠깐 동안만 브라우저 탭을 일시적으로 먹통 상태로 만들었다가 복구하는 짧은 프리징 디버깅 명령입니다.
chrome://gpuclean 크롬이 확보하고 있던 그래픽 카드(GPU)의 비디오 메모리 콘텍스트와 그래픽 캐시를 강제로 완전 초기화(클린)합니다.
chrome://gpucrash 크롬 내부 그래픽 프로세스(GPU Process)를 강제로 크래시시켜, 화면이 잠시 깜빡인 후 그래픽 엔진이 재부팅되는 과정을 테스트합니다.
chrome://gpuhang 크롬 그래픽 처리 장치를 먹통 상태로 만들어 하드웨어 가속이 멈췄을 때 CPU가 이를 어떻게 우회 감지하는지 테스트합니다.
chrome://memory-exhaust 메모리 고갈 유발: 가상으로 무한 메모리 할당을 시도하여 시스템의 RAM을 바닥내고, 크롬의 '메모리 부족 오류(OOM)' 대응 장치를 기동시킵니다.
chrome://memory-pressure-critical 운영체제로부터 "시스템 메모리가 완전히 고갈 직전(심각)"이라는 페이크 경고 신호를 강제로 날려, 크롬이 백그라운드 캐시를 급히 비우게 만듭니다.
chrome://memory-pressure-moderate 시스템 메모리가 부족해지기 시작했다는 "주의" 신호를 강제로 유발해 브라우저의 가비지 컬렉션(GC)을 유도합니다.
chrome://inducebrowserheapcorruption 브라우저 커널의 힙(Heap) 메모리 영역의 주소값을 인위적으로 손상시켜 힙 오염 보안 차단 장치를 기동합니다.
chrome://crash/cfg 윈도우 보안 기술인 제어 흐름 보호(Control Flow Guard) 위반 크래시가 일어났을 때 브라우저가 안전하게 프로세스를 방어하는지 테스트합니다.
chrome://heapcorruptioncrash 프로그램 메모리 관리 영역인 힙 공간을 즉시 오염시켜 크래시를 유도하는 디버깅 옵션입니다.
chrome://webuijserror (명령어 트리거) 입력 즉시 내부 관리 스크립트 전역에 강제로 자바스크립트 런타임 예외 오동작을 발동시킵니다.
chrome://quit 크롬 깔끔하게 종료: 주소창에 치는 순간 열려 있는 모든 크롬 창과 세션을 안전하게 데이터 저장한 후 브라우저 프로그램을 완전히 정상 종료시킵니다.
chrome://restart 크롬 재시작: 현재 열린 모든 탭과 창을 기억해 둔 채 브라우저를 즉시 완전히 껐다가 1초 만에 그대로 복구하며 자동 재실행합니다.
