머리카락엔 어느새 서릿발이 내려 앉은게 선연하게 보이네요. 어느새 나도 모르게 내려 앉은 새하얀 서리에 내심 몰라고는 하지만, 뒤돌아보면 참으로 함난하고도 질긴 생명이라는 사념도 하게 됨니다.

진정. 낮은 자리에서 좀 더 바름으로 선학들의 가르침에 더 다가가려했고, 축처진 동료나 후학들에게는 그나마 작은 어깨라도 내어주려고 했담니다. 몰라서도 그러하겠지만 더더욱 다른 이들보다 한번 더 경험했고, 증명하고 검증하면서 일인의 외진 구석의 하나의 사용자로서, 최종 사용자로서 보안이라는 부문과 개발이라는 조그마한 일부분으로 자리하게 되면서 무수히도 많은 시간들을 머리카락을 쥐어뜯고 뽑으면서 시간이 흐르는지 세월이 가는지도 모르게 살아 온 듯한 회감이 듬니다.
