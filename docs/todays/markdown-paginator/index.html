Global Commands

You can write these commands only at the beginning of the document.

  • --theme
  • --text-font
  • --title-font
  • --code-font
  • --font-size

Formatting Commands

You can write these commands at start of the page, before any text.

  • --A0
  • --A1
  • --A2
  • --A3
  • --A4
  • --A5
  • --A6
  • --A7
  • --A8
  • --A9
  • --A10
  • --page-width
  • --page-height
  • --margin-top
  • --margin-bottom
  • --margin-left
  • --margin-right
  • --binding-size
  • --binding-top
  • --header-no
  • --header-yes
  • --header-text
  • --footer-no
  • --footer-yes

Live Commands

You can write this commands everywhere in the markdown source

  • --index
  • --new-line

The following commands works "from this point onward"

  • :--- set alignment to left
  • ---: set alignment to right
  • :---: set alignment to center
  • ::: reset alignment
  • :100%: set width to 100%
  • :---%: reset width
