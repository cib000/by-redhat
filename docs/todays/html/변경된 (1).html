문서 제목 (H1)

문서에 대한 간단한 설명을 작성합니다.
이 문서는 마크다운 문법 예시를 포함합니다.

  • 작성자: 이름
  • 작성일: YYYY-MM-DD
  • 목적: 문서 예시 / 설명용 / 학습용

1. 개요 (H2)

이 섹션에서는 문서의 전체적인 목적과 범위를 설명합니다.

마크다운에서
문단을 나누려면 빈 줄이 필요하며,
줄바꿈을 강제로 하려면 문장 끝에 공백 두 칸을 넣습니다.

2. 제목 레벨 예시

H1 제목

H2 제목

H3 제목

H4 제목

H5 제목
H6 제목

3. 텍스트 스타일

  • 굵은 글씨
  • 기울임 글씨
  • 굵고 기울임
  • ~~취소선~~

중요한 내용은 강조하고,
~~더 이상 유효하지 않은 내용~~은 취소선으로 표시합니다.

4. 목록(List)

4-1. 순서 없는 목록

  • 항목 A
  • 항목 B
    • 하위 항목 B-1
    • 하위 항목 B-2
      • 더 깊은 단계

4-2. 순서 있는 목록

  1. 첫 번째 단계
  2. 두 번째 단계
  3. 세 번째 단계

4-3. 혼합 목록

  1. 준비 사항
    • 도구 설치
    • 환경 확인
  2. 실행
    • 명령 실행
    • 결과 확인

5. 체크리스트 (할 일 목록)

  • [ ] 해야 할 작업 1
  • [ ] 해야 할 작업 2
  • [x] 완료된 작업
