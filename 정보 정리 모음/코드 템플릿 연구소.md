## 1. 기본 아이디어
- **목표:** 초보자부터 고급자까지 코드 + 설명을 쉽게 작성, 공유, 재사용
- **방식:** 단일 HTML 파일 중심의 **로컬 + 선택적 공유 구조**

## 2. 사용자 흐름

### A. 작성/편집
**왼쪽 영역 (Input)**
- 언어 선택 드롭다운 (`AutoIt`, `HTML`, `CSS`, `JavaScript`, `JSON`, `VBS`, `PowerShell` 등)
- 코드 입력란 (`textarea`)
- 버튼
  - `➕ 추가` → 오른쪽 미리보기 영역으로 이동  
  - `🧾 붙여넣기` → 클립보드에서 코드 가져오기

**오른쪽 영역 (Preview/Editor)**
- 코드 + 설명 블록 (`code-box`)
- 복사 버튼 2개
  - `코드만 복사` → 코드만 클립보드에
  - `영역 복사` → 코드 + 설명 영역 전체 복사
- 각 블록은 **수정 가능 설명 영역** 포함
- Prism.js로 문법 하이라이팅



### B. 저장
- `💾 저장` 버튼 클릭 시
  - 전체 미리보기 영역(`dynamicContent`) 내용 가져오기
  - **단일 HTML 파일** 생성
  - 로컬 저장 → 나중에 다시 열어볼 수 있음



### C. 활용/공유

**로컬 활용**
- 다운로드한 HTML 파일을 폴더에 모아둠
- 앱 실행 → 폴더 목록 표시
- 원하는 문서 클릭 → 미리보기 + 복사 가능
- 초보자는 그대로 참고, 고급자는 코드 재활용 가능
<br><br>


**공유**
- 작성한 HTML 파일 그대로 공유 가능
- 서버/FTP 없이도 바로 사용 가능
- 다른 사람은 파일 열기만 하면 활용 가능

## 4. 단일 HTML 저장 구조 예시

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="utf-8">
    <title>코드 템플릿</title>
    <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/prism/1.29.0/themes/prism.min.css">
</head>
<body>
<section>
  <div class="code-box">
    <button class="copy-btn" onclick="copyCode(this)">코드만 복사</button>
    <button class="copy-btn" onclick="copyArea(this)">영역 복사</button>
    <pre><code class="language-autoit">…코드…</code></pre>
    <div class="editable">…설명…</div>
  </div>
</section>
<script src="https://cdn.jsdelivr.net/npm/prismjs@1.29.0/prism.js"></script>
<script>
function copyCode(btn){ /* 코드만 복사 */ }
function copyArea(btn){ /* 코드 + 설명 복사 */ }
Prism.highlightAll();
</script>
</body>
</html>
```

## 5. 장점


접근성: 초보자도 쉽게 볼 수 있음

재사용성: 코드/설명만 복사 가능

확장성: 언어 선택, Prism 지원 언어 추가 가능

보안/안정성: 로컬 중심, 서버 최소 의존

공유 용이: 단일 HTML 파일만 공유
